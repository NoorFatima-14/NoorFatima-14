### 📈 Featured Projects

#### 🪪 SecureID: Forgery Detection for Pakistani CNIC (Final Year Project)
A two-stage multimodal system that detects forged identity documents.
- Creates a unique 20-digit identity code to verify the authenticity of a person.
- Reached **99.85% accuracy** on a 2,000-sample test set of genuine and tampered cards (metadata swap, image swap, and mixed swap).
- Built with a Flask backend and a React frontend for registering and verifying IDs.
- 📄 Patent pending in Pakistan. Supervised by Dr. Naeem Akhtar.
- **Tech**: Python, PyTorch, CLIP, Flask, React

#### 👁️ Real-Time Attention Monitoring System
A multi-person system that tracks attention in real time.
- Uses **MediaPipe** face landmarks and the **Eye Aspect Ratio (EAR)** with blink detection logic.
- Includes an interactive dashboard.
- **Tech**: Python, MediaPipe, OpenCV

#### 📚 DocChat: Chat with Your PDFs
A document Q&A app built on a **RAG** pipeline.
- Uses LangChain, FAISS, and Hugging Face embeddings for semantic PDF search, with Gemini to write answers.
- Deployed as a Streamlit app.
- **Tech**: Python, LangChain, FAISS, Hugging Face, Streamlit

#### 💻 Earlier C++ Projects
- **Inventory Management System**: manages large inventories efficiently.
- **Parking System**: tracks and manages parking spaces automatically.
- **ATM Machine Simulation**: mirrors real ATM functions.
- **Phone Directory**: stores contacts using efficient data structures.
- **RSA Cryptography**: implementation of the RSA algorithm.
